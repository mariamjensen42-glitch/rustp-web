# Rust Web 项目功能扩展 - 实现计划

## [x] 任务 1：实现评论回复功能
- **优先级**：P0
- **依赖**：None
- **描述**：
  - 扩展评论模型，支持嵌套回复结构
  - 实现获取评论回复列表的API
  - 添加回复评论的功能
  - 支持对回复的批准和删除操作
- **验收标准**：AC-1
- **测试要求**：
  - `programmatic` TR-1.1：POST /api/posts/{id}/comments 能够创建回复评论
  - `programmatic` TR-1.2：GET /api/comments/{id}/replies 能够获取评论的回复列表
  - `programmatic` TR-1.3：PUT /api/comments/{id}/approve 能够批准回复评论
  - `programmatic` TR-1.4：DELETE /api/comments/{id} 能够删除回复评论
- **备注**：需要确保评论的嵌套层级合理，避免过深的嵌套结构
